# m·deko

Application Mac (Apple Silicon) pour une décoratrice d'intérieur : base de meubles et objets façon e-commerce, création de projets clients, génération de design books (PDF + PPTX) et assistant IA pour retoucher les rendus 3D.

Projet personnel, en cours de développement. Le contexte et les décisions sont dans [CLAUDE.md](CLAUDE.md).

Aucune donnée client n'est versionnée dans ce dépôt.
